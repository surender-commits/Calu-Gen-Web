# Calu Gen Web

A simple and lightweight web application for practicing mental math calculations. Calu Gen Web instantly generates calculation questions based on the selected difficulty level and allows users to reveal answers with a single click.


## Screenshots

<img src="https://github.com/surender-commits/Calu-Gen-Web/blob/main/Calu-Gen-Web.jpg"  width="auto" height="auto" >


## Features

* Generate random calculation questions instantly
* Multiple difficulty levels
* One-click answer reveal
* Clean and distraction-free interface
* Fast and lightweight frontend application
* No login or account required
* Responsive design

## How It Works

1. Choose a difficulty level from the dropdown menu.
2. A random calculation question is generated automatically.
3. Solve the question mentally or on paper.
4. Click **Show Answer** to reveal the correct solution.
5. Generate another question and continue practicing.

## Difficulty Levels

The app supports different number lengths and difficulty settings to help users gradually improve their mental calculation skills.
